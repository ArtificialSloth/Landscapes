# The per-setting benchmark, climbing up (owner, 2026-11-02): what each setting costs when it is the
# only thing switched on. The mirror of setting-sweep.txt, which started on Ultra and switched
# one thing off at a time.
#
# Same viewpoint and conditions: the owner's save spot (valley, facing north) in a frozen copy of
# `vintage cave tales-2`, view distance 32, his eight other mods and graphics settings, sweep off,
# clock stopped at noon. The floor is Performance with everything else off too: Farseer off, every

# Performance's values: Cache 2,048, detail target 3, band reach 33%, Farseer reach 4,096.

# fog and reach need Farseer, the Plants switches need Plant Detail, sheets and leaf shapes need
# Plant Textures too) is measured inside a block that turns the parent on first, between two stops
# of the parent alone; the block ends back on the floor. Distant Lights is measured last, at midnight.
#
